# 🎮 Ma Ville Monde — Toca-Monde

Jeu 2D style Toca Boca, 100% offline, pour Android.

## ✅ Fonctionnalités
- 👧 Personnage déplaçable au doigt
- 🏠 Maison avec objets interactifs
- 🌳 Parc navigable
- 🔄 Navigation entre lieux
- 💾 Sauvegarde automatique
- 📱 APK généré automatiquement

## 📱 Télécharger l'APK
→ Va dans **Actions** → dernier workflow → **Artifacts** → `MaVilleMonde-APK`

## 🎮 Jouer localement
Ouvre `godot-project/project.godot` dans Godot 4.3 → main.tscn ▶️
